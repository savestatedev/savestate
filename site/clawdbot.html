A restart is not a restore

Clawdbot died. The gateway came back. Without the workspace, the next process has no soul, no memory, no skills, no routing. It answers like it just met you.

This is the first-party adapter — the one SaveState is built against. We do not stop at a rules file.

What we snapshot in Clawdbot

Full extract and restore of the agent, not a vendor sidecar.

  • SOUL.md + identity SOUL.md, USER.md, AGENTS.md, TOOLS.md, and the other identity files that name the agent.
  • MEMORY.md + memory/ Standalone memory files and the memory/ directory. Written back on restore.
  • Skills skills/*/SKILL.md plus the scripts that make each skill real.
  • Gateway config openclaw.json / clawdbot.json under ~/.openclaw (or the legacy ~/.clawdbot / ~/.moltbot dirs). Secrets redacted by default.
  • Conversations Session JSONL under the gateway agents directory. Metadata always; content when the file fits.

Credentials stay out unless you opt in. Channel tokens are a re-auth after restore, not something we silently copy. That is the honest first-party path — not the same as Cursor’s community adapter, and we do not pretend it is.

Each snapshot is a SaveState Archive, encrypted with AES-256-GCM before it leaves the machine. You hold the passphrase.
