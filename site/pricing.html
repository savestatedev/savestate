Claim the API key

After you pay, claim the API key yourself from the claim URL. Then savestate login. Card today. No waitlist.

  1. POST https://savestate.dev/v1/keys with an empty JSON body. The response is HTTP 402 and always includes pay_url and claim_url.
  2. Open pay_url. That is Stripe Checkout for Pro at $9/mo. The Team Payment Link is $29/mo.
  3. Poll claim_url. Unpaid stays 402. Processing is 202. Issued is 200 once, with api_key. Store that key. Claimed is 409. Expired is 410.
  4. Send Authorization: Bearer <api_key>, or run savestate login.

Local snapshot, search, and MCP (npx -y @savestate/cli mcp) stay free and do not need an API key.
