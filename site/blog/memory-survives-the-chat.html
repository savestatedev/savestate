The thread always dies

If you work in Claude Code, Cursor, or Clawdbot, you already know the pattern:

  • Claude Code hits the context ceiling and compaction writes a digest. Goals survive. The reasoning does not.
  • Cursor closes the composer or starts a new chat. The agent that knew your project is gone.
  • Clawdbot ends the session. Personality, tools, and the last useful thread stay behind.

The workaround is always the same: re-explain. Paste the CONTEXT.md. Replay the decisions. Hope the next window holds long enough to finish the work.

That is time you should not spend twice.

Snapshot now. Restore tomorrow.

SaveState is the portable, encrypted memory layer for the tools you already use. Capture conversations, memories, custom instructions, and config. Search it. Restore it. Move it to the next client.

  • Snapshot Claude Code, Cursor, or Clawdbot before the window fills
  • Restore that memory in the morning — or in a different tool
  • Search across snapshots without reopening every thread
  • Keep the keys. AES-256-GCM. We never see plaintext.

The chat can end. Compaction can run. You can switch from Cursor to Claude Code tomorrow. The archive is still yours.
