A summary is not the session

Compaction is doing its job. The window is finite. Claude Code writes a digest so the session can continue.

The digest keeps the latest plan, the files it touched, and a short account of the outcome. It does not keep the approach you already rejected, the constraint you said once, or the dead end that explains the helper. The repo still has the diff. It does not have the judgment.

Keep that judgment outside the window

SaveState snapshots Claude Code: CLAUDE.md, project memory under .claude/, and the global settings the next session needs. Each snapshot is a SaveState Archive, encrypted with AES-256-GCM before it leaves the machine. You hold the passphrase.

Search it later. Restore it on another machine. The compact can run. The agent still knows why the code looks the way it does.
