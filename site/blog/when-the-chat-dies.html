The chat is not the memory

Claude Code, Cursor, and Clawdbot already remember things. Rules files. MCP configs. Composer threads. Workspace SQLite. A soul.md. The problem is ownership.

That memory lives where the vendor put it. Close the window and you cannot search last Tuesday. Switch machines and you start over. The agent that knew your repo, your taste, your constraints — gone with the tab.

A transcript export is not a memory layer. A chat history is not a restore.

What you actually keep

SaveState snapshots the identity, not the window:

  • Claude Code — instructions, tools, project memory, conversation state.
  • Cursor — MCP servers, rules, Composer history from workspace storage.
  • Clawdbot — agent identity, memories, and the config the next process needs to be the same agent.

Each snapshot is a SaveState Archive, encrypted with AES-256-GCM before it leaves the machine. You hold the passphrase. We never see the keys.

Search it later. Restore it on another box. Move it across clients. The chat can die. The archive does not.
