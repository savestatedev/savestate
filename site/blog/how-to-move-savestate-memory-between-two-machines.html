How to Move SaveState Memory Between Two Machines

The ciphertext stays in that computer's home directory until you copy the file.

Two computers do not share ~/.savestate. This walk-through uses two temp HOME directories, /tmp/savestate-two-machines/machine-a and /tmp/savestate-two-machines/machine-b, each with its own project. Machine A is the desk. Machine B is the laptop.

The commands were npx --no-install @savestate/cli, linked to the SaveState CLI built from this repository at version 0.9.0, so these transcripts come from this repository. After you install the package, the same subcommands are npx @savestate/cli. The passphrase desk-to-laptop-demo exists only for this temp project.

For the adapter, see Claude Code. Snapshots are a SaveState Archive, encrypted with AES-256-GCM before they are stored. savestate cloud push is the remote move, and it requires a Pro or Team login. This session had no API key, so the move that worked was a copy of the local .saf.enc file.

Snapshot on the desk

Commands in this section ran in /tmp/savestate-two-machines/machine-a/project. CLAUDE.md was:

# Ferry

The laptop handoff token is ferry-token-9.
Keep the billing note from the desk machine.
Restore this file on the second machine before the next deploy.

$ export SAVESTATE_PASSPHRASE='desk-to-laptop-demo'

Copying machine A's project directory would keep machine A's absolute path. On a second computer that path is not the snapshot. Init on the laptop writes the laptop's home instead.

Cloud push does not run without a login

cloud push is how a Pro or Team account sends the local snapshot to SaveState cloud, where the other machine can pull it. This CLI was not logged in. The command ran back on machine A, where the snapshot exists. It exits 1 and uploads nothing.

$ npx --no-install @savestate/cli cloud push

- Verifying subscription...
✖ Subscription required

  Not logged in. Run `savestate login` first.

Pro cloud storage is the remote path. It is not required for this move. The ciphertext is already a file on the desk.

The index is not the archive

list, restore with no id, and search read .savestate/index.json in the project. The ciphertext is ss-2026-10-18T21-36-23-7w2fps.saf.enc in the storage path. Init does not create $HOME/.savestate. That directory appears when a snapshot is written. Copying the archive into a missing directory fails:

$ cp -v /tmp/savestate-two-machines/machine-a/.savestate/ss-2026-10-18T21-36-23-7w2fps.saf.enc /tmp/savestate-two-machines/machine-b/.savestate/
cp: cannot create regular file '/tmp/savestate-two-machines/machine-b/.savestate/': Not a directory
