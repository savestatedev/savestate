How to Restore a Claude Code Project After a Crash

CLAUDE.md was overwritten. The latest encrypted snapshot put it back.

A crash can leave CLAUDE.md as a stub. The repo still builds. The billing rule the agent was following lived in that file, and the file is now wrong.

This is the recovery, run against the SaveState CLI built from this repository at version 0.9.0. The commands were npx --no-install @savestate/cli, linked to that local build, so these transcripts come from this repository. After you install the package, the same subcommands are npx @savestate/cli. The passphrase ledger-crash-demo exists only for this temp project.

For the adapter itself, see Claude Code. Snapshots are a SaveState Archive, encrypted with AES-256-GCM before they are stored.

A project worth restoring

HOME pointed at an empty temp directory, so the Claude Code adapter only read the fixture. The project was two files. CLAUDE.md:

# Ledger

Billing retries must use the idempotency key invoice-replay-7.
Never double-charge a customer after a crash.
Restore this file before the next deploy.

.claude/settings.json allowed Bash(npm test).

$ npx --no-install @savestate/cli --version
0.9.0

Init with the passphrase already set

$ export SAVESTATE_PASSPHRASE='ledger-crash-demo'
$ npx --no-install @savestate/cli init

The Claude Code adapter saw CLAUDE.md. Init took the passphrase from the environment and returned without a prompt.

Snapshot without a passphrase

Clear the variable and snapshot. The command exits 1 and stores nothing.

$ env -u SAVESTATE_PASSPHRASE npx --no-install @savestate/cli snapshot


✗ Snapshot failed
No passphrase available. Set SAVESTATE_PASSPHRASE environment variable or run in an interactive terminal.

Put the passphrase back, then snapshot

$ export SAVESTATE_PASSPHRASE='ledger-crash-demo'
$ npx --no-install @savestate/cli snapshot

That archive is ss-2026-10-17T21-40-56-vpigps. Twelve files, 1.5 KB, encrypted, stored locally.

Crash the project file

$ printf 'CORRUPTED AFTER CRASH\n' > CLAUDE.md
$ cat CLAUDE.md
CORRUPTED AFTER CRASH

Restore latest

restore with no id selects the newest snapshot.

$ npx --no-install @savestate/cli restore
